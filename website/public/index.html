Ferry

百度网盘下载工具，macOS 版

使用 Swift 开发、隐私优先，专注于稳定、高效地下载文件。

Download GitHub macOS 14.0+

用法

  1. 1

    登录百度账号

    在百度的官方登录页中登录。

  2. 2

    复制分享链接

    切到 Ferry，它读取剪贴板中的链接和提取码。

  3. 3

    勾选文件，下载

    文件保留分享中的目录结构。

细节

  • 不触发限速

    默认一个连接。超级会员可以在设置中调高。

  • 无服务器

    凭据存在 macOS 钥匙串中，不经过第三方。

  • 开源

    全部代码在 GitHub 上。

问答

能突破会员限速吗？
不能。Ferry 不绕过百度的会员限速。
为什么开发这个客户端？
我希望日常的网盘下载可以更轻、更简单，尽量减少安装体积和系统资源占用。同时，通过开放源代码，让应用的行为与数据处理方式更透明。

Ferry 与百度公司没有关联。“百度网盘”是百度公司的商标。
